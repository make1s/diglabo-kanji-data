# 描画の基本APIを実行環境から独立させる

教材開発者がWeb表示とサーバーでの教材生成に同じ描画を使えるよう、描画の基本APIはブラウザのDOMや特定のフレームワークに依存せず、JavaScript／TypeScriptからSVGを生成できる形とする。React専用のAPIより呼び出し側の組み込み作業は増えるが、ブラウザとNode.jsに共通する描画を保守できる。React向けには利用例を提供する。

公開APIの入口は文字データからの手本SVG生成とし、表示する画の範囲・色・部品の指定を追加できる形にする。同じ名前の部品が複数ある文字にも対応するため、部品の選択には名前だけでなく部品識別子を使い、出典・ライセンス情報も取得できるようにする。
